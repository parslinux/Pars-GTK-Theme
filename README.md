# 🐆 Pars GTK Theme

**Status: Alpha (v0.2.0)**

Official GTK theme for Pars Linux.

Pars GTK Theme is a clean, modern and minimal GTK theme designed for GNOME and XFCE desktop environments.

## Features

- Minimal design
- Dark navy color palette
- Pars blue accents
- GNOME support
- XFCE support

## Current Status

Version: **v0.2.0**

### Changes

- Imported Orchis Theme as upstream base
- Added Pars Blue accent palette
- Added Pars Dark Navy palette
- Initial branding work
