# 🐆 Pars GTK Theme

Official GTK theme for Pars Linux.

Pars GTK Theme is a clean, modern and minimal GTK theme designed for GNOME and XFCE desktop environments.

## Features

- Minimal design
- Dark navy color palette
- Pars blue accents
- GNOME support
- XFCE support
